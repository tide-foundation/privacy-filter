# Disclaimer

Redacted can help remove sensitive text. It does not guarantee that a document
is safe to share. Review the entire output before relying on it or sharing it.

## Detection and document limits

The model can miss sensitive information or flag ordinary text. Sensitivity is
a detection setting, not an accuracy or confidence score. Images are not scanned
for sensitive information, and the app does not perform OCR. Scanned documents
need separate OCR before processing. Preserved images and other content can
still reveal private information. Check the scan report for warnings and
limitations.

Formatting may change. If the original layout cannot be preserved, the app can
produce a clean text rewrite. Synthetic replacements are fictional and should
not be treated as factual information. Fixed masks do not reveal the original
character count through the replacement text, but preserved layouts may still
reveal dimensions or spacing.

## Processing and privacy

The local server can see document contents while processing them. Guest
filenames and detected original values remain in temporary memory; generated
guest files are temporary too. Hiding a value behind a black bar in the
interface is not encryption. Authentication and encrypted history are not yet
available.

Deleting a result does not remove files you have downloaded, backups or copies
outside the app. Temporary storage and application cleanup do not guarantee
forensic erasure. Review those copies and handle them appropriately.

output correctness or suitability for a particular purpose. You are responsible
